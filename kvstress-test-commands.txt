KVSTRESS TEST COMMANDS FOR PAPER TURBOQUANT

All commands below write unique output files into:
/srv/share/ollama-benchmark/results

All commands below use `--timeout 0`, which means unlimited runtime.

Container compose file:
/srv/share/ollama-benchmark/ollama-main-turboquant/docker-compose.ollama-bench.yml

0. Native baseline GPU verification
Tests:
- stock Ollama at `11438` can load and run on GPU
- `full_gpu_residency` is true for the baseline host
- baseline is suitable for regression and product-outcome comparisons

If this run shows CPU-only or mixed residency, do not use:
- regression
- product-outcome

Instead, use:
- turbo-benefit
- capacity
- spill

docker compose -f /srv/share/ollama-benchmark/ollama-main-turboquant/docker-compose.ollama-bench.yml exec ollama-bench kvstress-bench \
  --hosts http://127.0.0.1:11438 \
  --host-labels baseline \
  --model qwen3-30b:instruct2507-udq4kxl \
  --kv-modes f16 \
  --workloads decode-growth \
  --num-ctx 4096 \
  --concurrency 1 \
  --warmup 0 \
  --epochs 1 \
  --timeout 0 \
  --output /results/native_baseline_gpu_check_paper.csv \
  --jsonl-output /results/native_baseline_gpu_check_paper.jsonl \
  --summary-output /results/native_baseline_gpu_check_paper.txt
